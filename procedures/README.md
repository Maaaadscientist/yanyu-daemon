# Installed Smart Procedures

This directory contains stable JSON procedures loaded automatically by
`procedure_runner.py` and `tracking_click.py`.

Generate and install a procedure with `control_recorder.py --smart --install`.
The timestamped raw recording stays under `recordings/`; the installed copy is
written here and can be reviewed or committed independently.

Do not enable a procedure until it has:

- at least one coordinate-verified movement action;
- an exact `refresh_anchor` on the kill/harvest click;
- a successful run from its declared/required start context through `procedure_runner.py` or the production daily runner. Repository tests live under `tests/`; `test.py` is not the test suite despite its historical name.

Reusable route fragments are regular JSON files with `"library": true` and
`"enabled": false`. Include one from another procedure with:

```json
{"type": "include", "procedure": "_fragment_name"}
```

The loader expands fragments recursively and rejects missing or circular
references. `_dali_travel_to_cow_area.json` is the current working example.

`aligned_click` maps a canonical point from `alignment_image` onto the current
window with ORB/RANSAC before clicking. Pair it with a region-scoped
`expect_text` so a visually aligned but wrong destination cannot be confirmed.

For time-critical multi-jump input, use `rapid_clicks` generated by the
recorder's F5 mode. Do not copy those clicks into a legacy tuple route.
